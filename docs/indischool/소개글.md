# 인디스쿨 소개글

## 제목

한 명이라도 빠지면 완성 못 하는 모둠 퍼즐

## 본문

안녕하세요! 모둠이 함께 맞추는 직소 퍼즐 '조각조각'을 만들어서 소개해요.

학급 세우기 시간에 퍼즐을 하면 꼭 잘하는 한두 명만 맞추고 나머지는 구경하더라고요. 그래서 조각을 모둠 친구들에게 나눠 줘서, 모두가 참여해야 완성되는 퍼즐을 만들었어요.

**1. 그림 고르고 수업 열기**
선생님은 구글 계정으로 로그인해요. 사진·삽화·명화·우리 그림 365장 중에 고르거나 직접 찍은 사진을 올리고, 조각 수(12~96)와 모둠 수만 정하면 수업 코드가 나와요.
📷 [사진 01] 수업 만들기

**2. 코드로 들어오고, 모둠은 끌어서**
학생은 로그인 없이 6자리 코드(또는 QR)와 이름만 넣어요. 들어온 이름을 모둠 칸으로 끌어 넣거나 '무작위로 나누기'를 누르면 돼요.
📷 [사진 02] 대기실·모둠 편성

**3. 내 조각은 나만 꺼낼 수 있어요**
조각이 모둠 친구들 상자에 골고루 나뉘어요. 판에 꺼낸 조각은 누구나 옮길 수 있고, 친구가 잡은 조각은 친구 색 테두리로 보여요. 맞는 자리 가까이 놓으면 자석처럼 딱 붙어요.
📷 [사진 03] 학생 화면
다 맞추면 모둠 모두에게 완성 화면과 걸린 시간이 나와요.
📷 [사진 04] 완성 화면

**4. 모둠 한눈에 보기**
모둠마다 얼마나 맞췄는지 선생님 화면에 바로바로 보여요. 전자칠판에 띄워 두기 좋고, 모둠끼리 순위는 보여 주지 않아요.
📷 [사진 05] 모둠 한눈에 보기

**5. 혼자서도 맞춰 볼 수 있어요**
코드 없이 첫 화면 '혼자 맞춰 보기'에서 그림과 조각 수를 골라 바로 연습해요. 먼저 끝낸 모둠은 완성 화면에서 '기다리는 동안 혼자 맞춰 보기'로 이어 가고, 선생님도 수업을 열기 전에 미리 맞춰 볼 수 있어요.
📷 [사진 06] 혼자 맞춰 보기
